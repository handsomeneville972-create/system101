# Find'em brief
Flow: /findem → /findem/[profession] → /groups/[slug]
- Enter: reason ≥50 chars → join_requests pending → members vote 48h, 80% yes = pass, leader tie-break, deny = 7d cooldown + feedback.
- Create: /groups/new, 2 invites must accept 72h → active, else archived.
- RLS: groups readable all; inserts leader-only; votes member-only. Denial = 7d cooldown + feedback (implemented).
